## 윈도우에서 개발환경 세팅

새 윈도우 PC에 깃에서 클론받아 실행.

- `npm install` → `npm start` 순서. 폰(아이폰 Expo Go)과 PC가 같은 와이파이면 QR로 실행됨 — **맥 없이도 iOS 개발 가능** (Metro가 JS만 서빙하는 구조라서)
- **트러블슈팅**: `TypeError: configs.toReversed is not a function`
  - 원인: Node v18. `toReversed()`는 Node 20+ 문법 (설치 때 `EBADENGINE` 경고가 힌트였음)
  - 해결: `winget install OpenJS.NodeJS.LTS` → 터미널 재시작 → Node 22 확인
  - 교훈: npm WARN이라고 다 무시하면 안 됨. `required: { node: '>= 20.19.4' }`가 답을 알려주고 있었다

## 이미지 정사각형 → 직사각형

물고기 사진은 대부분 가로로 길어서 정사각형 프레임(`cover` 모드)에서는 머리/꼬리가 잘림.

- 도감/즐겨찾기 썸네일: 48×48 → **72×48 (3:2)**
- 상세 화면: 220×220 → 처음엔 `width: '100%'` + `aspectRatio: 3/2`로 했다가, 원본이 작은 사진(멸치)이 과하게 확대되어 뿌옇게 보이는 문제 → **고정 300×220**으로 조정
- 배운 것: RN `Image` 기본 `resizeMode`는 `cover`(꽉 채우고 넘치는 부분 자름). `aspectRatio` 스타일로 비율 고정 가능

## "내가 본 물고기" 기능 (1~3단계, 직접 타이핑)

즐겨찾기와 같은 패턴을 **참고서 삼아 처음부터 직접 작성**. 같은 패턴을 두 번째 만들면서 Context 구조가 손에 익음.

| 단계 | 한 일 |
|---|---|
| 1 | `context/seen.tsx` 작성 — `SeenProvider` + `useSeen` 훅 (favorites.tsx 참고) |
| 2 | `app/_layout.tsx`에서 `SeenProvider`로 앱 감싸기 |
| 3 | 상세 화면에 "👀 봤어요 / 🔍 아직 못 봤어요" 토글 버튼 + 스타일 |

배운 것:

- **AsyncStorage key = 서랍 이름표**: `STORAGE_KEY`를 `'favorites'` 그대로 두면 읽을 때 즐겨찾기 데이터가 들어오고, 쓸 때는 즐겨찾기 데이터를 **덮어써버림**. 기능마다 자기 서랍(key)이 있어야 함
- **조건부 스타일**: `style={[A, 조건 && B]}` — 배열로 주면 겹쳐 발라지고(뒤가 우선), `조건 && B`는 참일 때만 B를 추가하는 React 단골 패턴
- **JSX 삼항연산자**: `{조건 ? A : B}`로 상태에 따라 다른 내용 표시

### 오늘의 버그: `return context;` 누락

`useSeen()`에서 에러 체크만 하고 `return context;`를 빼먹음.

- 증상: 화면에서 `const { isSeen } = useSeen()`이 참조 불가 (빨간 줄)
- 원리: JS 함수가 `return` 없이 끝나면 **`undefined`를 반환** → `undefined`에서 구조 분해를 하려니 실패
- TypeScript가 반환 타입을 `void`로 추론해서 **실행 전에** 에디터에서 잡아줌 — 이게 TS를 쓰는 이유
