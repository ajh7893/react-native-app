# 2026-07-21 어류 도감 앱 개발 기록

3단계(실제 API 연동)와 즐겨찾기, 실제 어류 사진 적용까지 완성한 날.

## 3단계: OBIS API 연동 — 진짜 관측 데이터로 지도 채우기

만든/수정한 파일:

| 파일 | 역할 |
|---|---|
| `lib/obis.ts` | OBIS API 호출 함수 (`fetchObservations`) |
| `app/(tabs)/map.tsx` | 샘플 좌표 대신 API에서 받아온 실제 관측 위치를 마커로 표시 |

- **OBIS**(Ocean Biodiversity Information System): 해양생물 출현 기록 API. 회원가입/API 키 없이 무료 사용
- 학명(`scientificName`)으로 검색하고, 한반도 근해 사각형 범위(WKT `POLYGON`)로 제한
  - 전 세계 데이터를 다 받으면 태평양 한복판까지 점이 찍혀서 지도가 의미 없어짐
- `exclude=ON_LAND`: 좌표가 육지로 찍힌 의심스러운 기록(반올림된 표본 좌표, 기관 주소 등)은 제외

배운 것:

- **fetch**: 웹에서 쓰던 fetch가 React Native에도 똑같이 내장되어 있음
- **async/await**: 시간이 걸리는 작업(네트워크 요청)을 기다렸다가 결과를 받는 문법. `async` 함수는 `Promise`를 반환
- **useEffect**: "화면이 처음 나타날 때 딱 한 번 실행할 일"을 등록하는 훅. 두 번째 인자 `[]`가 빈 배열이면 처음 한 번만 실행
  - **cleanup 함수**: useEffect에서 return한 함수는 화면을 나갈 때 실행됨. `cancelled` 플래그로 "화면을 벗어났는데 늦게 도착한 응답이 상태를 덮어쓰는 것"을 방지
- **Promise.allSettled**: 어류 10종을 동시에(병렬로) 요청. `Promise.all`과 달리 하나가 실패해도 나머지 결과는 그대로 받을 수 있음
- **로딩 상태 패턴**: `loading` state + `ActivityIndicator`로 "불러오는 중..." 오버레이 표시

## 즐겨찾기 기능 (Context + AsyncStorage)

만든/수정한 파일:

| 파일 | 역할 |
|---|---|
| `context/favorites.tsx` | 즐겨찾기 Context/Provider (`useFavorites` 훅) |
| `app/(tabs)/favorites.tsx` | 즐겨찾기 탭 (새 탭 추가) |
| `app/fish/[id].tsx` | 헤더 오른쪽 별표 버튼으로 즐겨찾기 토글 |
| `app/(tabs)/index.tsx` | 즐겨찾기한 어류에 ⭐ 표시 |

배운 것:

- **Context**: 여러 화면이 같은 데이터를 공유해야 할 때 쓰는 장치. useState는 한 화면 안에서만 살아있는데, 즐겨찾기는 상세 화면(토글)·도감 목록(별 표시)·즐겨찾기 탭(목록) 세 화면이 같은 데이터를 봐야 함
  - 구조: `createContext`(통로 만들기) → `Provider`(데이터 보관소)로 앱 전체 감싸기 → 각 화면에서 커스텀 훅(`useFavorites`)으로 꺼내 쓰기
  - Provider 밖에서 실수로 쓰면 에러를 던지는 안전장치 패턴
- **AsyncStorage**: 앱을 껐다 켜도 데이터가 남는 폰 내부 저장소 (웹의 localStorage와 비슷하지만 비동기)
  - 문자열만 저장 가능 → `JSON.stringify`로 저장, `JSON.parse`로 복원
- **불변성 규칙**: React에서는 기존 배열을 직접 바꾸지 않고 항상 새 배열(`filter`, 스프레드 `[...arr, x]`)로 교체해야 상태 변경을 알아챔

## 어류 사진 적용

- `assets/images/fish/`에 어종별 사진 추가, `data/fish.ts`에 `image` 필드 연결
- 도감 목록/즐겨찾기 썸네일, 상세 화면 사진, 지도 마커에 적용
- **커스텀 마커**: `<Marker>` 안에 자식 요소를 넣으면 기본 핀 대신 그 요소가 마커가 됨 — 동그란 흰 테두리(`borderRadius` = 너비의 절반, `overflow: 'hidden'`) 안에 물고기 사진을 넣음
- 사진이 없는 어종은 이모지로 대체 (`image ? <Image> : <Text>` 조건부 렌더링)
