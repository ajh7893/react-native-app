# 2026-07-20 어류 도감 앱 개발 기록

React Native를 처음 시작하며 어류 도감 앱의 1~2단계를 완성한 날.

## 프로젝트 목표

어류 도감 앱 만들기.

- 어류 정보를 목록/상세로 보여주는 **도감**
- 어류가 관찰된 위치를 보여주는 **지도**
- (예정) 실제 API에서 관찰 데이터 가져오기

## 기술 선택

- **React Native + Expo** — 웹(JS/React) 경험을 살릴 수 있어서 선택
- **Expo SDK 54** — Expo Go 앱으로 폰에서 바로 확인하기 위해 "For learning with Expo Go" 옵션 선택 (최신 SDK 57은 개발 빌드가 따로 필요함)
- 에디터: IntelliJ (그래들 import 알림은 안드로이드 네이티브용이라 무시하면 됨)

## 프로젝트 생성 및 실행

```bash
npx create-expo-app@latest my-app   # SDK 54 (Expo Go용) 선택
cd my-app
npx expo start                       # QR 코드가 뜸
```

- 아이폰에 **Expo Go** 앱 설치 후 카메라로 QR을 찍으면 폰에서 앱 실행
  - "사용 가능한 데이터가 없음"이 뜨면 → Expo Go 미설치가 원인
  - 폰과 맥이 같은 와이파이여야 함. 안 되면 `npx expo start --tunnel`
- `npm run ios`는 Xcode(시뮬레이터)가 필요하므로 당장은 사용 안 함
- 파일을 저장하면 폰에 자동 반영됨 (**Fast Refresh**)
- 터미널 단축키: `r` 리로드, `w` 웹 브라우저로 열기
- 새 라이브러리를 설치했을 때만 서버 재시작 필요: `npx expo start --clear`

## 1단계: 도감 목록 + 상세 화면

만든 파일:

| 파일 | 역할 |
|---|---|
| `data/fish.ts` | 어류 10종 샘플 데이터 (지도용 관찰 좌표 포함) |
| `app/(tabs)/index.tsx` | 도감 목록 화면 (검색 기능 포함) |
| `app/fish/[id].tsx` | 어류 상세 화면 |

배운 것:

- **expo-router**: `app/` 폴더의 파일 구조가 곧 화면 구조 (Next.js와 유사)
  - `(tabs)` 괄호 폴더 = 주소에 안 나타나는 그룹 폴더
  - `[id].tsx` 대괄호 파일 = 동적 라우트. `/fish/1`, `/fish/2` 모두 이 파일이 처리하고 `useLocalSearchParams()`로 값을 꺼냄
- **useState**: 상태가 바뀌면 React가 화면을 자동으로 다시 그림. 반드시 `setXxx` 함수로 바꿔야 React가 알아챔
- **FlatList**: 긴 목록을 효율적으로 그리는 컴포넌트
- **컴포넌트 분리**: 반복되는 UI는 작은 컴포넌트(`InfoRow`)로 추출
- **React 구동 원리**: 컴포넌트 = 상태를 받아 화면 설계도(JSX)를 반환하는 함수. 상태 변경 → 함수 재실행 → 이전 설계도와 비교(diffing) → 바뀐 부분만 실제 화면에 반영

## 2단계: 지도 탭

```bash
npx expo install react-native-maps
```

- `app/(tabs)/explore.tsx` 삭제 → `app/(tabs)/map.tsx` 생성, 탭 이름을 "지도"로 변경
- 아이폰은 애플 지도를 쓰므로 **API 키 없이 Expo Go에서 바로 동작**
- 어류 10종 × 위치 2곳 = 마커 20개를 `flatMap`으로 표시
- 마커 → 말풍선(callout) → 누르면 상세 화면으로 이동 (`onCalloutPress`)
- `pinColor`로 마커 색 변경 가능
- `initialRegion`으로 지도 시작 위치/줌 설정 (delta 값 = 얼마나 넓게 볼지)

배운 것:

- **key prop**: 반복 렌더링하는 요소마다 고유한 `key` 필수 — diffing 때 React가 요소를 알아보는 이름표
- **제약**: `react-native-maps`는 웹 미지원. 웹에서는 도감 탭만 동작하고, 웹 지도가 필요해지면 `map.web.tsx`로 플랫폼 분기하면 됨
